# 🤝 Code of Conduct

Ordo is an open source project committed to providing a friendly, safe, and welcoming environment for all contributors.

We expect all participants to:
- be respectful and considerate
- assume good intent
- be inclusive and constructive
- avoid harassment and abusive behavior

## Scope
This Code of Conduct applies to all project spaces:
- GitHub issues, PRs, discussions
- community chats
- in-person events (if any)

## Unacceptable Behavior
- harassment, discrimination, hate speech
- personal attacks or insults
- trolling, intimidation, or threats
- doxxing or sharing private information
- repeated disruption of discussions

## Enforcement
Project maintainers are responsible for clarifying standards and may take corrective action for any behavior they deem inappropriate.

If you experience or witness unacceptable behavior, please contact the maintainers by opening a private report (or email if configured).
